ブレイクゲート

Python PyQt マルチスレッド 個人開発

「休憩を忘れて作業し続ける」「タイマーを無視してしまう」という課題に着目し、 先行研究の「インタラクティブな通知であれば休憩への移行を促進できる」という知見をもとに要件を整理。 単なる通知ではなく、ゲームを通じて内発的動機から自然な休憩移行を促す仕組みを設計・実装しました。

  • 担当：企画・設計・実装・動作確認（すべて個人）
  • 技術：作業中もバックグラウンドでゲームを自動進行させるマルチスレッド処理
  • 工夫：他者に使ってもらいフィードバックを得ながら改善。ヒーローズ・リーグ2025に出展

クロスノーツ

Python Pygame MIDI リアルタイム処理 学会発表

操作方式の異なるプレイヤー同士が同じ曲で対戦できる音楽ゲーム。 縦スクロール型・横スクロール型など複数の操作方式を1つのゲームに統合し、 遊び方の違うプレイヤー同士でも競い合える体験を設計・実装しました。情報処理学会で発表。

  • ゲームループ：Pygameによるリアルタイム描画・入力処理
  • 判定：タイミング精度（最大コンボ／JUST数／サドンデス等）を計測する当たり判定
  • 譜面：楽曲のMIDIデータから譜面を自動生成し、難易度を調整するアルゴリズム
  • 対戦：画面を左右分割し、異なる操作方式でも同一楽曲で同時プレイ
